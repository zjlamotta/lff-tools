# LFF Acquisition Tools — Cowork/Claude Code skill marketplace

Private marketplace for LFF's deal-workflow skills (om-screen, underwrite, om-deep-dive,
broker-questions, comp-pull-spec, tax-bill-parse, refresh-market, lp-log, deal-log, brief,
compile, lint, sync).

Install: Cowork → Settings → Plugins → Add marketplace → `zjlamotta/lff-tools` → install **LFF Acquisition Tools**.

Canonical source lives in the KB at `lff-platform/cowork/marketplace/`; this repo is the publish target.
